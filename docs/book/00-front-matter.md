## How to Read This Manual

COSMOS is easiest to misunderstand when several different layers are treated as one thing. This book uses an evidence taxonomy throughout:

| Label | Meaning | What a reader may conclude |
| --- | --- | --- |
| IMPLEMENTED | Code path or persisted runtime component exists. | The mechanism is present in software; this alone does not prove it improves performance. |
| OBSERVED | A runtime log or state record shows the component executed. | The component ran in at least the captured environment. |
| MEASURED | A defined metric was produced by a reproducible or described benchmark. | The reported metric can be evaluated on its stated scope. |
| NULL | A test failed to show the hypothesized advantage. | The tested claim is unsupported under that experiment; the null is part of the result. |
| HYPOTHESIS | A falsifiable research proposition. | It is a question to test, not a fact to repeat. |
| METAPHOR / MODEL | A conceptual lens such as 'cosmic synapse' or 'organism'. | Useful for design thinking, but not literal physics or biology unless independently demonstrated. |

| Non-negotiable scientific boundary Nothing in the public loss curves, memory behavior, autonomous loops, sensory integration, or quantum provenance establishes machine consciousness. The engineering claim is modular persistent cognition-like software behavior; inner experience is not measured here. |
| --- |

### The One-Sentence System Definition

COSMOS is a local-first experimental cognitive runtime that binds a language model, dynamic internal-state mechanisms, persistent and semantic memory, Hebbian/plasticity systems, a multi-organ CNS controller, live sensory summaries, an autonomous heartbeat, file/action lanes, and IBM/Azure quantum entropy provenance into one owner-controlled response and learning loop.

### The Core Loop in Plain English

```text
INPUT
  ↓
clean / classify / route
  ↓
retrieve relevant long-term memory
  ↓
attach live sensory + bio summaries when fresh
  ↓
construct entropy / quantum provenance packet
  ↓
update compact internal state (12D; optional 42D/54D paths)
  ↓
modulate attention / swarm selection / response policy
  ↓
generate local response
  ↓
store conversation + learned associations + telemetry
  ↓
heartbeat later consolidates, reflects, checks health, and queues curiosity
  ↺
```
The phrase used in the source for the backbone is: “perceive, compress, expand, validate, express, store.” The value of the project is not any one noun in that sentence; it is the repeated closed-loop coupling among them.
