## APPENDIX E — A READER'S REPRODUCTION CHECKLIST

- Read the model card and FINDINGS.md before repeating any headline.
- Verify the exact model lineage being discussed.
- Run the architecture baseline first.
- Run preflight assertions before trusting a state-kernel benchmark.
- Freeze corpus and record its hash.
- Use multiple seeds and publish per-seed numbers.
- Report absolute loss and parameter cost separately.
- Preserve nulls and retractions.
- Separate simulator data from hardware data.
- Do not publish private paired conversation data simply to make a result reproducible.
- Treat spectral/frequency language as a hypothesis unless a benchmark operationalizes it.
- Never infer consciousness from persistence, autonomy, loss, or self-description.
