## APPENDIX D — CANONICAL CLAIM MAP

| Claim | Status | Canonical wording |
| --- | --- | --- |
| COSMOS has persistent memory across sessions. | IMPLEMENTED / OBSERVED | COSMOS loads stored conversation/history and supports semantic retrieval when the memory layer is available. |
| The 12D state improves the tested transformer. | MEASURED, bounded | dyn12 improved the small frozen-corpus baseline in the published state ladder; broader generalization requires more datasets/seeds/models. |
| 54D is always better than 12D. | FALSE in current evidence | More complex state rungs did not outperform dyn12 in the cited controlled small-model ladder. |
| Quantum makes COSMOS smarter. | UNSUPPORTED / NULL | Matched quantum injection tests did not show predictive advantage. |
| Quantum birth is auditable. | MEASURED | Specific from-scratch artifacts have published measurement archives, mapping tests, hashes, and deterministic seed/weight checks. |
| Sensory state improves text prediction. | NULL under current paired benchmark | Aligned measured state did not beat plain attention, although it beat some destroyed-pairing conditioned controls. |
| COSMOS is conscious. | NOT ESTABLISHED | The project measures software state, learning, memory, and behavior; no consciousness conclusion follows. |
| The old frequency/spectral theory is proven. | HYPOTHESIS | Spectral/frequency claims remain a research program requiring strong empirical baselines. |
| The heartbeat is a literal biological heartbeat. | METAPHOR / IMPLEMENTED SCHEDULER | It is a proactive timed task loop for consolidation, reflection, health, and curiosity. |
| Forever memory means infinite context. | NO | It means durable retention plus retrieval over old experiences; generation still uses a finite selected context. |
